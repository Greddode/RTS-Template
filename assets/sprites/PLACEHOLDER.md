# Placeholder art

Every PNG in this folder is **placeholder art**: simple shapes drawn by a small program for the
RTS Kit, so the sprite system has something to show and you have templates to paint over.
Replace them with your own art (same file names); delete one and that type is drawn as a
coloured shape. Rules (names, sizes, tinting) are in the README, section "Art (sprites)".

The placeholder files (24):

- `buildings/`: `academy.png`, `air_factory.png`, `archery_range.png`, `barracks.png`, `base.png`, `dock.png`, `guard_tower.png`
- `tiles/`: `dirt.png`, `grass.png`, `gravel.png`, `lava.png`, `rock.png`, `water.png`
- `units/`: `airship.png`, `archer.png`, `boat.png`, `falcon.png`, `knight.png`, `mage.png`, `medic.png`, `melee.png`, `scout.png`, `ship.png`, `worker.png`
